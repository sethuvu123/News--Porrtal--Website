# News Portal Website

A modern, responsive news portal frontend built with HTML5, CSS3, and JavaScript. The project provides a clean interface for discovering news, browsing categories, and viewing article previews across different devices.

## Overview

The News Portal Website is a frontend web development project designed to demonstrate responsive UI design, interactive web elements, and structured content presentation. It focuses on delivering a user-friendly browsing experience with a clean layout and organized news sections.

## Key Features

- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **News Categories** — Organizes articles into relevant sections.
- **Article Previews** — Displays news headlines, images, and summaries.
- **Search Functionality** — Helps users find news, if implemented.
- **Interactive UI** — Uses JavaScript to enhance user interaction.
- **Clean Layout** — Provides clear navigation and readable content.

## Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, layout, and responsive design |
| JavaScript | Interactive functionality and dynamic behavior |

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sethuvu123/News--Portal--Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd News--Portal--Website
   ```

3. Open the folder in Visual Studio Code.

4. Run `index.html` using Live Server or open it directly in your browser.
